# 🌌 Kahve ile Evren Yeniden Başlatma Simülatörü

**Dünyanın (ve evrenin) en ciddi, en bilimsel, en abartılı ve tamamen gereksiz projesi.**

Evrende bir şeyler ters gidiyorsa, muhtemelen kahve yetersizliğindendir. Bu simülatör, kaç fincan kahve içerek evreni yeniden başlatabileceğinizi **bilimsel olarak** (kesinlikle değil) hesaplar.

## 🚀 Özellikler
- Gerçekten çalışan Python kodu (inanmıyorsan çalıştır)
- Kaos seviyene göre kahve miktarı hesaplama
- Dramatik geri sayım ile evren yeniden başlatma
- Rastgele komik sonuçlar
- Hiçbir şey yapmayan ama orada duran gizli bir şey
- Aşırı ciddi README (bu)

## 📋 Kurulum ve Kullanım
```bash
git clone https://github.com/Tentivory/kahve-ile-evren-yeniden-baslatma-simulatoru.git
cd kahve-ile-evren-yeniden-baslatma-simulatoru
python3 evren_yeniden_baslat.py
```

Kahvelerini iç, kaos seviyenini gir, onay ver ve evreni kurtar. Sorumluluk tamamen sende. (Yok, bizde.)
